Spola, Flatpak repository

This is where the Flatpak of Spola lives. Current version: 0.3.33.

Install Spola

Or from a terminal:

flatpak install https://daniel-g-carrasco.github.io/spola/spola.flatpakref

Updates arrive on their own, through GNOME Software or flatpak update. The GNOME runtime comes from Flathub.

The repository is signed. The key's fingerprint is in the README. Source and issues are on GitHub.
