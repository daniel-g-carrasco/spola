# Security policy

Report vulnerabilities privately to code@danielgrasso.com. Include the
affected version, operating system and installation method, a description
of the impact, and the minimum information needed to investigate. Use
sample data and redact account details, app passwords, share links and file
paths from any attachments.

Please allow time to investigate and prepare a fix before public disclosure.
When applicable, fixes and affected versions will be documented in
[GitHub Security Advisories](https://github.com/daniel-g-carrasco/spola/security/advisories).
