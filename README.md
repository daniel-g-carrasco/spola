# koofr-sync (provisional name)

A native GNOME (GTK 4 + libadwaita) client that keeps local folders in two-way sync with Koofr, built on `rclone bisync`, with a tray icon and Nautilus emblems.

Status: design phase. The design document (in Italian) is [docs/progetto.md](docs/progetto.md). No code yet.

Not affiliated with Koofr.
